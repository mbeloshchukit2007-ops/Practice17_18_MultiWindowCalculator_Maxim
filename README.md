# Практична робота №17-18

Тема: розробка додатку з декількома вікнами.

## Що зроблено

- Створено Windows Forms додаток калькулятора.
- Додано головну форму `CalculatorForm`.
- Додано другу форму `ClearConfirmForm` для підтвердження очищення.
- При натисканні на кнопку `CE` відкривається модальне вікно через `ShowDialog()`.
- Кнопка `Так` повертає `DialogResult.Yes`, після чого калькулятор очищується.
- Кнопка `Ні` повертає `DialogResult.No`, і дані залишаються без змін.
- Додано перемикачі `ON` і `OFF` для увімкнення та вимкнення кнопок.
- Папки `bin`, `obj` і `.vs` не додаються до Git.

Варіант виконання зроблений окремо для Максима.
